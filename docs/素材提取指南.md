# KrkrDump 素材提取操作流程（魔女的夜宴 · xmoe 汉化版）

> 结论：本作全部 xp3 被 xmoe 二次封加密（文件名 MD5 哈希化、数据自定义变换）。KrkrExtract **Lite 版不支持静态解 xp3**（只接受 .exe），完整版官方也**不支持自定义引擎**，故均不通。**可靠方案是 KrkrDump 动态 dump**：它捕获运行中游戏实际读取的文件，能同时解决解密与文件名映射。
> 工具与配置已就绪，流程如下（需你在本机操作）。

## 一、已就绪

- 工具已复制到**游戏根目录**（与 `魔女的夜宴.exe` 同目录）：
  - `KrkrDump.dll` + `KrkrDump.json` + `KrkrDumpLoader.exe`
- 配置文件 `KrkrDump.json` 要点：
  - `outputDirectory`: `E:\dump\sanoba_witch`（dump 输出，纯英文）
  - `enableExtract`: `true`
  - `excludeExtensions`: `.ogg/.opus/.wav`（只取立绘/CG/剧本；要音频可清空）
  - `decryptSimpleCrypt`: `true`

## 二、操作步骤

### 1. 把游戏放到纯英文路径（强烈建议）
- 当前游戏路径含日文 `サノバウィッチ Sanoba Witch`，可能使 KrkrDump 异常。
- **建议**：把整个游戏目录（含全部 xp3、exe、xmoe dll 及已放好的 KrkrDump 三件）复制到纯英文路径，如 `E:\sanoba\`，再从那里运行。

### 2. 拖动启动
- 把 **`魔女的夜宴.exe`**（汉化玩家入口）拖到游戏根目录的 `KrkrDumpLoader.exe` 上。
- 游戏将带 dump 插件启动。若启动失败：① 确认已复制到英文路径；② 确认 KrkrDump.json 与 dll 同名同目录；③ 拖的是玩家入口 exe。

### 3. 挂机跑全剧情拿全素材
- 进入游戏后，**手动点过全部对白、选项、五条个人线**，并打开全 CG / 立绘鉴赏页。
- 游戏运行时读取到的资源会实时输出到 `E:\dump\sanoba_witch`：
  - `*_fg*.tlg` → 人物立绘差分
  - `*_ev*.pimg` → 事件CG
  - `*.ks` / `*.scn` → 剧本
  - `.png` / `.jpg` → 部分图片
- ⚠️ 关键：KrkrDump 是"所见即所得"，**没跑到的剧情/素材不会输出**。要拿全，必须**跑完所有分支**（5条个人线 + 共通线 + 全CG）。

## 三、dump 后处理

1. **TLG 转 PNG**：用 GARbro 打开 dump 出的 `.tlg`，全选 → 转换多媒体 → PNG（勾选"自动跳过无法转换"），转完删原 tlg。
2. **立绘差分合成**：`krkrFgiEditor` 读取坐标文件（`.pbd`/json），按图层组（身体/表情）合成完整人物立绘。
3. **CG 差分合成**：`AutoCGAligner` 对齐合成 `.pimg` 完整 CG。
4. 按剧本引用命名，放到工程目录：
   - 人物立绘 → `环10/src/common/fg/<角色>_<位置>_<表情>_<服装>.png`
   - 事件CG → `环10/src/common/ev/<ev名>.png`

## 四、映射说明
- 剧本对白带立绘引用 `[角色, 位置, 表情, 服装]`（如 `["秀明","出","15","制服"]`）。
- dump 出的立绘文件名 + 坐标文件能还原该对应关系；接入时我建立映射，让阅读器人物位按剧本精确显示。
