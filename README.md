# 魔女的夜宴 · 小米手环10

基于 Xiaomi Vela JS 快应用的视觉小说播放器，在小米手环 / 手表上阅读《魔女的夜宴》（サノバウィッチ）。

本仓库按设备分分支维护：本分支对应 **小米手环10**，默认分支为 **小米手环10**。

> 剧情文本与美术版权归 Yuzusoft 与相关汉化组所有，本工程仅作技术学习研究用途。

## 快速开始

1. 安装项目依赖：`npm install`。
2. 运行校验：`npm run check`。
3. 在 AIoT-IDE 中打开本目录，或运行 `npm run start`。
4. 发布包使用 `npm run release`。

视觉资源索引：`npm run index:visual`（生成 `docs/资源索引.json` 与 `docs/资源缺口.md`，两者为生成物，不入库）。

默认配置是 233dp 圆屏手表。要修改包名、名称、版本、目标设备和 `designWidth`，编辑 `src/manifest.json`。每次重新发布同一应用包时都必须递增 `versionCode`。
